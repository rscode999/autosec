# AutoSec (Automatic Secretary)

Automatically scans a Slack channel for announcements, converts the announcements into a listserv email, and sends the email.


## Setup Instructions

To use AutoSec, you need to have [Python](https://www.python.org/downloads/), Microsoft Outlook, and the [Slack desktop app](https://slack.com/downloads/) installed.  

AutoSec has been tested on Python 3.15.

### Python Package Installation

Create a virtual environment in the *project root directory*:
```
python -m venv .venv
```

Activate the environment:
```
# Mac or Linux
source .venv/bin/activate

# Windows
.venv\Scripts\Activate.ps1
```

Install the required packages `pywin32`, `requests`, and `slack_sdk`:
```
python -m pip install pywin32 requests slack_sdk
```

### AutoSec Configuration

#### Creating a Slack Bot

1. Go to the [Slack API dashboard](https://api.slack.com/apps).
2. If the bot `autosec` is not already there, select "Create New App". Otherwise, you may skip the remaining bot assignment steps.
3. Select "Starter App", then "Continue".
4. Name the bot something you want. Select the workspace where you intend to use AutoSec. Continue to "Review App".
5. Under "Configurations", click "Edit Permissions". To the bot's Bot Token Scopes, add the permissions `channels:history`, `channels:read`, `chat:write`, `commands`, `files:read`, `groups:history`, and `groups:read`. Continue to "Create and Install", then authorize your bot to access Slack.

#### Assigning Slack Bot Token

1. On the [Slack API dashboard](https://api.slack.com/apps), select the bot that you just created.
2. Under "OAuth and Permissions", copy your Bot User OAuth Token. It should start with "xoxb-".
3. Paste the bot token in AutoSec's token area, in `.tokens/tokens.json` in the "bot_token" field. 

#### Assigning Channel ID

1. Open your Slack desktop app. Open the channel containing the announcements.
2. Select the 3 dots in the upper right corner, then go to "Channel details" -> "Open channel details".
3. Scroll to the bottom of the "About" tab. At the bottom, you should see "Channel ID: CXXXXX". Copy the channel ID into the "channel_id" field of `.tokens/tokens.json`.

#### Assigning Listserv Email

1. Set the "recipient_email" field of `.tokens/tokens.json` to the email address to send listservs to.


## Run Instructions

Activate the app's virtual environment:
```
# Mac or Linux
source .venv/bin/activate

# Windows
.venv\Scripts\Activate.ps1
```

If you want, change the email's subject, header, or footer in `content/email_content.json`.

Run the script `main.py`:
```
python main.py
```

Use the `-v` flag to print extra information: `python main.py -v`

Warnings are printed in yellow. Fatal errors are printed in red.

On a successful run, the finished email will have been sent to the intended recipient, and will not print anything unless the `-v` flag is used.

To remove automatically generated announcements from the email content file, run the cleaning script from the project root directory:
```
python clean.py
```

## File Structure

### Directories
- `.tokens` contains sensitive authentication data. Its contents should never be pushed to a public repo.
- `content` contains JSON files that define announcements and emails.
- `images` contains pictures used **in every email**, including those in the email footer.
- `images_slack` (generated during an AutoSec run) contains images from a **Slack channel**.

### Files
- `autosec_colors`- module for printing in different colors
- `autosec_constants`- module containing constants (including paths to files and directories) used in all AutoSec scripts
- `clean.py`- standalone script to undo generated announcements
- `combine.py`- module that inserts announcements into a pre-existing JSON containing the email's subject, header, footer
- `main.py`- standalone script, AutoSec's entry point
- `outlook.py`- module for converrting an email JSON, generated by `combine.py`, into a HTML Outlook email and sending it
- `slack.py`- module for scraping a Slack channel, downloading its images, and converting its content into an announcement JSON file
